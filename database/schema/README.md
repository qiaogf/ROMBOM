# Database Schema

## 文件说明

- `products.sql` - 产品表结构
- `suppliers.sql` - 供应商表结构
- `orders.sql` - 订单表结构
- `customers.sql` - 客户表结构
- `bom.sql` - 物料清单表结构
- `pricing.sql` - 定价表结构

## 快速开始

使用Docker启动数据库：

```bash
cd docker
docker-compose up -d
```

使用Adminer访问数据库：http://localhost:8080

连接信息：
- 服务器：mysql
- 用户名：rombom
- 密码：rombom123456
- 数据库：rombom
